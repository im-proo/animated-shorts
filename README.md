# 🎬 3D+2D Cartoon Animated Shorts

A complete Remotion + Three.js + Postprocessing pipeline for creating viral 2D cartoon animated story shorts in 3D worlds.

### 🚀 1-Click Render on Google Colab (Free GPU)
1. Click the **Open in Colab** badge above or visit:
   [https://colab.research.google.com/github/im-proo/animated-shorts/blob/main/render_animation.ipynb](https://colab.research.google.com/github/im-proo/animated-shorts/blob/main/render_animation.ipynb)
2. In Colab, verify the GPU runtime: **Runtime > Change runtime type > T4 GPU**.
3. Click **Runtime > Run all** (`Ctrl+F9`).
4. The video renders in ~3 minutes and automatically downloads to your device!
